# Shahd Abd Almoiez — Developer Portfolio

A responsive React portfolio with a classic navy-blue visual identity.

## Run locally

1. Install Node.js (LTS).
2. Extract this project folder.
3. Open a terminal in the project folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Before publishing

- Add your GitHub repository URLs and live demo URLs in the `projects` array in `src/main.jsx`.
- Review the CV-based experience descriptions and confirm that every statement reflects your actual work.
- Add a professional headshot if you want one in the About section.
- Confirm the public contact details you want displayed.
- Deploy the project to Vercel or Netlify.

## Tech

React, Vite, Lucide React, CSS.
